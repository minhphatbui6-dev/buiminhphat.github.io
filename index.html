BLACK HAT (Mu Den)

Nguoi xau, hack vi tien, pha hoai.
Cach hoat dong:
1. Trinh sat (Recon): Thu thap thong tin muc tieu
2. Quet (Scan): Nmap, Nessus tim lo hong
3. Khai thac (Exploit): Dung Metasploit, SQLMap
4. Hau khai thac: Cai backdoor, danh cap du lieu
5. Xoa log, an dau vet, ban du lieu tren dark web

Cong cu: Metasploit, Cobalt Strike, Mimikatz, Empire, Burp Suite

WHITE HAT (Mu Trang)

Nguoi tot, bao ve he thong.
Cach hoat dong:
1. Lap ke hoach: Ky hop dong, xac dinh pham vi
2. Trinh sat: Thu thap thong tin CO PHEP
3. Quet va liet ke: Tim lo hong, ghi chep
4. Khai thac co kiem soat: Chi lay PoC, khong gay hai
5. Bao cao: Viet report, danh gia CVSS, de xuat sua loi

Chung chi: CEH, OSCP, CISSP, GPEN

GREY HAT (Mu Xam)

O giua, xam nhap khong xin phep nhung khong gay hai.
Thuong tim lo hong tinh co -> bao cho chu he thong.
Co the yeu cau tien thuong. Neu bi tu choi, cong khai sau 90 ngay.
Rui ro phap ly cao vi xam nhap trai phep.

BLUE HAT (Mu Xanh Duong)

Cach cai virus vao the SD:

1. AUTORUN VIRUS:
Tao file autorun.inf:
[AutoRun]
open=virus.exe
action=Open folder to view files
-> Khi cam vao may, Windows tu chay virus.exe

2. GIA MAO DUOI FILE:
Dung ky tu Unicode U+202E de dao nguoc ten file.
"photo.jpg[U+202E]exe.scr" -> Windows hien thi "photo.scr.jpg"
Thuc chat la file .scr (executable)!

3. SHORTCUT VIRUS:
Tao shortcut den virus.bat. Doi icon thanh icon anh/thu muc.
Nan nhan click mo -> Virus chay ngam + anh that mo ra danh lua.

4. PAYLOAD TRONG FILE ANH:
copy /b cat.jpg + virus.exe secret.jpg
File secret.jpg van mo duoc nhu anh binh thuong.
Ben trong chua virus.exe.

5. ANDROID MALWARE QUA THE SD:
Copy file virus.apk vao the SD voi ten hap dan.
"Game_hay.apk", "Mod_YouTube.apk"
Nan nhan cai dat -> Dien thoai bi nhiem.

PHONG CHONG:
Khong cam the SD la vao may
Tat AutoRun/AutoPlay trong Windows
Quet virus truoc khi mo
Format the SD la truoc khi dung
